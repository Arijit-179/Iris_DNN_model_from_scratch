# Iris_DNN_model_from_scratch
This project implements a Deep Neural Network (DNN) from scratch in NumPy to classify the famous Iris dataset into three species:
1.Setosa
2.Versicolor
3.Virginica
This Iris dataset is imported using pandas and a DNN is created with 1 input layer, 2 hidden layers and 1 output layer. backpropagation algorithim is used to train the DNN without using any in_built libraries like pytorch, tensorflow etc.
